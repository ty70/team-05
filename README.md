# 5市 ごみ分別比較ナビ

5つの架空自治体のごみ分別データを、品目名から検索・比較できるWebアプリです。クラウドワークスのチーム開発案件でAIを使って制作しました。

## 主な機能

- **24の共通品目**について、5市の分別区分を一覧比較
- 品目名による検索、自治体ごとの出し方・条件・注意事項の表示
- パソコン・スマートフォンに対応した画面レイアウト

## 技術・工夫

HTML / CSS / JavaScript、CSV、Git / GitHubを使用。自治体ごとに異なる品目名や分別区分を整理し、元の区分と比較用の共通区分を併記しました。

## 担当範囲

**私の担当：** 鷹取市データの加工・形式修正、検索・5市比較UIの実装、条件表示の補完と動作修正。

**チームの成果：** 他の4市のデータ整備、表示内容の改善、複数メンバーによる確認・検証。

## 起動方法

このまま、ダブルクリックしても、index.htmlは開きません。

index.html をダウンロードしていただくか、このリポジトリをクローンしてくだされば、

ブラウザで開くと利用できます。

CSVを利用するため、ローカルサーバーでの起動を推奨します。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

> **注記：** 使用データは架空自治体のサンプルであり、実際のごみ分別案内には利用できません。
