# 配布物

## ページの開き方

`index.html` をダブルクリックで開いても、表は表示されません。
ブラウザの制限で、CSV を読み込めないためです。

次の「方法1」か「方法2」のどちらかで開いてください。
VS Code を使っている人は、方法1が簡単です。

### 方法1：VS Code の Live Server を使う

1. VS Code で、このフォルダを開く（メニューの「ファイル」→「フォルダーを開く」）
2. 左端の拡張機能アイコン（四角が4つ並んだ形）を押し、「Live Server」を検索してインストールする
3. 左のファイル一覧で `index.html` を右クリックし、「Open with Live Server」を選ぶ

ブラウザが開き、ページが表示されます。

### 方法2：Python を使う

#### (1) このフォルダでターミナルを開く

**Windows**

1. エクスプローラーで、このフォルダを開く
2. 上部のアドレスバー（フォルダの場所が表示されている欄）をクリックする
3. `cmd` と入力して Enter を押す

黒い画面（コマンドプロンプト）が、このフォルダの場所で開きます。

**Mac**

1. 「アプリケーション」→「ユーティリティ」→「ターミナル」を開く
2. `cd ` と入力する（cd のあとに半角スペースを1つ）
3. Finder から、このフォルダをターミナルの画面にドラッグ＆ドロップする
4. Enter を押す

**VS Code を使っている場合**

このフォルダを開いた状態で、メニューの「ターミナル」→「新しいターミナル」を選びます。

#### (2) サーバを起動する

ターミナルに次のコマンドを入力して、Enter を押します。

Windows：

```
python -m http.server 8000
```

Mac：

```
python3 -m http.server 8000
```

`Serving HTTP on ...` と表示されたら起動しています。
ブラウザで http://localhost:8000/ を開いてください。

ページを見ている間は、ターミナルを閉じないでください。
終わるときは、ターミナルで Ctrl + C を押します。

#### うまくいかないとき

**Windows で「Python が見つかりません」と出る、または Microsoft Store が開く**

Python が入っていません。次の手順で入れてください。

1. スタートメニューから「Microsoft Store」を開く
2. 「Python」を検索し、「Python 3.xx」のうち番号がいちばん大きいものを選んで「入手」を押す
3. インストールが終わったら、ターミナルを一度閉じて、(1) からやり直す

python.org から入れた場合で `python` が動かないときは、`python` の代わりに `py` と入力してください。

```
py -m http.server 8000
```

**Mac で「コマンドライン・デベロッパ・ツール」のインストールを求められる**

「インストール」を押し、終わったら同じコマンドをもう一度実行してください。
