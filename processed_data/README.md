# 加工済みデータのルール

## 担当
- T05-A: 蒼井市（aoi.csv）、桜庭市（sakuraba.csv）
- T05-B: 柚木市（yuzuki.csv）
- T05-C: 水無瀬市（nimase.csv）
- T05-D: 鷹取市（takatori.csv）

## 共通フォーマット
各CSVは次の8列で統一します。

`市 / 元品目名 / 共通品目名 / 条件 / 自治体区分 / 共通区分 / 出し方 / 要チェック`

- 元品目名: 配布CSVの品目名を保持する
- 共通品目名: 5市横断表示に使うグループ名
- 条件: 「飲料用」「雨傘」など、元品目名に含まれる違いを残す
- 自治体区分: 配布データにある元の区分
- 共通区分: `可燃 / 不燃 / 資源 / 粗大 / 収集不可・処理困難 / その他` のいずれか
- 出し方: 配布データにある注意事項・説明
- 要チェック: 配布データだけでは判断を一意にできない場合のみ記入する

## 横断表示の共通品目
Discordで共有された一覧は実数24品目です。課題要件の「20件以上」を満たします。

CD・DVD、アルミ缶、ガラスびん、スチール缶、パソコン、ペットボトル、乾電池、傘、割りばし、包丁、布団、扇風機、新聞紙、段ボール、生ごみ、発泡スチロール、紙おむつ、自転車、蛍光灯、衣類、鏡、電子レンジ、靴、食用油

上記以外の行は削除せず、`共通品目名` を空欄にして元データを残します。

## 1対多の扱い
元データの行は統合・削除しません。同じ共通品目に複数行が対応する場合は、条件付きで複数行のまま保持します。

例:
- 日傘 → 共通品目名「傘」、条件「日傘」
- 雨傘 → 共通品目名「傘」、条件「雨傘」
- CD → 共通品目名「CD・DVD」、条件「CD」
- DVD → 共通品目名「CD・DVD」、条件「DVD」

柚木市のボタン電池は、チーム内合意に基づき「乾電池」、条件「ボタン」として扱います。

## 蒼井市の注意
蒼井市は自治体区分が「その他」の行が多いため、説明文から共通区分を読み取ります。
説明からも一意に判断できない行は無理に分類せず、共通区分を「その他」とし、理由を「要チェック」に残します。

## 検証
2026-10-05時点で、上記24共通品目は5市すべてに対応行があり、全加工済みCSVの共通区分は定義済み6区分の範囲内です。
